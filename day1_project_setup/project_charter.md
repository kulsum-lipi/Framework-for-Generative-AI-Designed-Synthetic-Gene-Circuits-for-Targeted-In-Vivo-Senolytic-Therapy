
# Project Charter - Senolytic AI: Paper 4

## 1. Project Scope
**In scope:**  
- Detect senescent vs non-senescent cells using scRNA-seq and spatial datasets.  
- Build a computational **Senescence Atlas**.  
- Benchmark classification models and generative AI pipeline for safety and efficiency.

**Out of scope:**  
- Lab experiments or in vivo testing (computational only).  
- Therapeutic deployment of circuits (future work).
