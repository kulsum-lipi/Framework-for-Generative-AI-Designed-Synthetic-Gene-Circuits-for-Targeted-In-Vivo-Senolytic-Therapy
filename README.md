# Senolytic AI – Paper 4

This repository contains all materials, code, and outputs for the Senolytic AI project (Paper 4). It is organized day-wise from Day 1 to Day 9 for clarity.

---

## 📁 Repository Structure

### Day 1
- **Project Setup**
  - `docs/` – Project charter, pipeline description & diagram, evaluation metrics, safety rubric, datasets, labeling plan, baseline plan.
  - `notebooks/00_getting_started.txt` – Starter notebook instructions.
- **Literature Review**
  - `Literature Review/Senolytics/` – 10 papers
  - `Literature Review/Gene Circuits/` – 10 papers
  - `Literature Review/Generative AI/` – 10 papers
  - `Mapping of Key Biological Entities – Senolytic Gene Circuit.gdoc` – Mapping doc

### Day 2
- `Biological Parts Mapping.gdoc` – Regulatory elements for senolytic targeting
- `AI Generative Model Comparison (Synthetic Biology).gdoc` – Generative model comparison table
- `sample_extraction.txt` – Sample text extraction

### Day 3
- **Datasets**
  - Promoter, motif, and drug/cellage CSVs
- **Results / Metrics**
  - `final_baseline_metrics.csv`, `final_motif_shortlist.csv`, `final_promoter_safety_scores.csv`
- **Test Data**
  - `X_test.csv`, `y_test.csv`

### Days 4–9
- `Day4.pdf` → Tiny model + “IF this THEN that” circuit
- `Day5.pdf` → AND/NOT circuits & simulation plot
- `Day6.pdf` → Safety check table (✅/❌)
- `Day7.pdf` → Full pipeline + 3-line analysis
- `Day8.pdf` → SHAP/attention figures + captions
- `Day9.pdf` → Methods, results, and limits (1-page text)
